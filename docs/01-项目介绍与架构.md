# ObjStoreExplorer — 项目介绍与架构

> 本文严格依据 v0.1.0 源码编写。所有功能描述、模块职责、参数取值均可在对应源文件中核实。
> 版本变更线索见根目录 [CHANGELOG.md](../CHANGELOG.md) 与 [05-开发日志](./05-开发日志.md)。

---

## 1. 项目概述

ObjStoreExplorer 是一个 **MinIO / S3 兼容对象存储管理工具**，提供两种交付形态：

| 形态 | 技术 | 定位 | 入口 |
|---|---|---|---|
| **桌面版** | 纯 Python 3.13 + Tkinter | 单人本地使用，含本地↔远端**同步**、反馈等本机能力 | `python -m objstoreexplorer` |
| **Web 容器版** | FastAPI + uvicorn + Docker | 浏览器多人访问，viewer/admin 两角色 | `docker compose up -d --build` |

两个形态**复用同一套** `core/`（S3 客户端 / 加密 / 管理器）、`services/`（传输 / 剪贴板 / 检索 / 同步）、
`config/` 业务层，数据目录互通（连接历史 / 操作日志共享）。桌面版**不监听任何网络端口**；
Web 版默认监听容器内 8000（compose 映射宿主 6083）。

**v0.1.0 是本项目的正式稳定版**。版本号单一真源为 `src/objstoreexplorer/config/settings.py` 的
`APP_VERSION`，`src/objstoreexplorer/webapp/__init__.py` 与 `docker-compose.yml` 镜像标签三处同号。

## 2. 核心设计原则

| 原则 | 说明 |
|---|---|
| **双形态复用** | 桌面 / Web 共享 `core` + `services` + `config` 业务层，差异只在入口与界面层，避免重复维护 |
| **版本号单一真源** | 只认 `config/settings.py:APP_VERSION`，`build.py` 读不到直接报错，不静默兜底；已移除 `OSE_VERSION` 覆盖机制 |
| **凭据仅存服务端** | AK/SK 用 Fernet 加密落盘，SK 永不回传前端；Web 口令 bcrypt 哈希；明确不采纳「浏览器持 SK」方案 |
| **统一异常与返回** | 统一异常体系（`ConfigError` / `AccessPermissionError` / `NotFoundError` 等）+ 统一返回 `(bool, str)` 模式 |
| **能力位感知** | `S3ClientBase` 运行时记录服务端明确不支持的操作，前端据此虚线降级，不对异构后端做统一假设 |
| **后台线程不卡 UI** | 桌面版所有耗时操作走后台线程 + 主线程桥（`ui/threading_bridge.py`），不跨线程碰 Tk |
| **下载原子性** | 临时文件 + `os.replace`，失败 / 取消不留半截文件、不覆盖本地旧文件 |
| **依赖上界 + CVE 门禁** | 全部依赖声明版本上界，与 `pip-audit` 实测结果一起维护（上界可能挡安全补丁，必须配合扫描核验） |

## 3. 功能总览

## 4. 模块结构与分层

代码按职责分为四层，桌面版与 Web 版共享下三层，仅最上层界面不同。源码采用 **src 布局**，
包目录 `objstoreexplorer` 位于 `src/objstoreexplorer/`，包目录名与发行名一致：

```
project-root/
├── src/objstoreexplorer/          # 包目录 = 发行名 objstoreexplorer
│   ├── __init__.py                # 包元信息 + __version__ 惰性转发
│   ├── __main__.py                # 支持 python -m objstoreexplorer
│   ├── main.py                    # 桌面版主入口 main()
│   ├── config/                    # 配置层：常量 + 异常体系 + 反馈配置模板
│   ├── core/                      # 核心层：S3 客户端 / 加密 / 桶 / 文件 / 管理器
│   ├── services/                  # 服务层：传输 / 同步 / 缓存 / 剪贴板 / 检索 / 权限
│   ├── ui/                        # 桌面版界面层（pages / widgets / windows / styles）
│   ├── utils/                     # 横切工具（诊断 / 图标 / 截图 / 线程池 / 编码 / 反馈）
│   ├── webapp/                    # Web 版（FastAPI 路由 / 模板 / 静态资源 / 账号库）
│   └── resources/icons/           # 189 个图标资源
├── main.py                        # 桌面版启动引导壳（PyInstaller 入口 / 源码直跑）
├── pyproject.toml                 # 构建配置（包名 / 入口点 / 包数据 / 动态版本）
├── requirements.txt               # 桌面版依赖（含 CVE 上界注释）
├── requirements-web.txt           # Web 版依赖（在桌面版之上追加）
├── Dockerfile / docker-compose.yml / deploy.sh / deploy.bat   # Web 版部署
├── build.py / build.spec          # 桌面版 PyInstaller 打包
├── docs/                          # 交付文档（5 篇编号文档）
├── README.md / CHANGELOG.md / LICENSE.md / AGENTS.md
```

### 4.1 config/ — 配置层

| 文件 | 职责 |
|---|---|
| `settings.py` | 全局常量：`APP_VERSION`（版本号唯一真源）、窗口尺寸、默认限额、路径常量 |
| `exceptions.py` | 统一异常体系，业务层与界面层共用 |
| `feedback.yaml.example` | 反馈平台配置模板（全占位符，真实 `feedback.yaml` 不入库） |

### 4.2 core/ — 业务核心层

| 文件 | 职责 |
|---|---|
| `s3_client_base.py` | S3 客户端抽象基类：接口契约 + 能力位 + 默认「不支持」实现 |
| `s3_client_v1.py` / `s3_client_v2.py` | minio-py V1 / V2 API 实现（列举 / 上传 / 下载 / 预签名 / Admin / 版本 / 策略 / CORS / 分片） |
| `s3_client_factory.py` | 按模块探测能力自动选择 V1/V2 客户端，调用方无感 |
| `encryption.py` | Fernet 加密：密钥原子创建 / 损坏检测 / 原子轮换 / 失败回滚 |
| `config_manager.py` | 连接历史 / 操作日志 / 应用设置的 SQLite 持久化（全参数化 SQL） |
| `bucket_manager.py` / `bucket_ext.py` | 桶管理（建 / 删 / 统计 / 策略 / CORS / 分片清理）+ 桶级 CORS REST 实现 |
| `file_manager.py` | 对象管理：上传 / 下载 / 重命名 / 复制剪切粘贴 / 批量删除 / 文件夹子树 / 属性 / 标签 / 预览 |
| `admin_manager.py` | MinIO Admin API：用户增删改 / 策略附加分离 / 一键创建整套（失败回滚） |
| `stats_manager.py` | 存储总览并发统计 |
| `validators.py` | 输入校验：endpoint 校验 / 文件名清洗 / 桶名 / AK 校验 |
| `error_hints.py` | S3 错误码人话映射（16 条规则，未命中原样透传） |

## 5. 关键技术选型

| 层 | 技术 |
|---|---|
| 桌面版 | Python 3.13+（实测 3.14.6 亦可）+ Tkinter（需含 tkinter 的 Python 发行版） |
| Web 版 | FastAPI + uvicorn + Jinja2 + 原生 JS（无前端构建链） |
| 存储 | minio-py（S3 兼容协议，自动适配 V1/V2 两套 API）；SQLite（连接历史 / 账号 / 日志 / 任务） |
| 加密 | cryptography（Fernet）；bcrypt（口令哈希） |
| 打包 | PyInstaller onedir（不用 onefile、不开 UPX，规避杀软误报） |
| 部署 | Docker + docker-compose（Web 版） |

## 6. 数据存储

运行期数据统一落在 `data/` 目录（首次启动自动创建，**不入库、不进交付包**）：

| 路径 | 内容 | 说明 |
|---|---|---|
| `data/explorer.key` | Fernet 主密钥 | ⚠ **务必备份**：丢失 = 库中所有已存 AK/SK 永久不可解密 |
| `data/db/config.db` | 桌面版加密数据库 | 连接历史、操作日志、应用设置 |
| `data/web/secret.key` | Web 版会话签名密钥 | 多 worker 共享 |
| `data/web/web.db` | Web 版账号库 | 账号、会话、任务注册表（WAL 模式） |
| `data/logs/` | 运行日志 | 反馈打包前自动脱敏 |
| `data/cache/` `data/temp/` `data/feedback_bundles/` `data/config/` | 缓存 / 临时 / 反馈包 / 反馈配置 | 自动清理或用户可编辑 |

数据目录基准为程序自身所在目录（源码运行时是**项目根**，打包后是 **exe 所在目录**）；
可用 `OSE_DATA_DIR` 环境变量重定向。详见 [02-环境部署教程](./02-环境部署教程.md)。

橙赭渐变品牌 + 奶油暖白画布 `#FAF7F2` + 大圆角几何（按钮 / 输入 8px、卡片 14px）+
浅色分层侧栏 + 胶囊选中导航 + 业务域分组导航 + 圆头线性 SVG 图标（stroke 2.0）+

→ 暮橙 Emberline（双形态归一，2026-11-12 换代）。

## 8. 设计决策（关键取舍）

| 决策 | 选择 | 理由 |
|---|---|---|
| 双形态复用 | 桌面 / Web 共享 `core`/`services`/`config` | 一套业务逻辑，两种界面，避免重复维护 |
| 版本号归一 | 桌面 0.1.0 与 Web 内部 2.x 归一为 v0.1.0 | 单一真源，消除「同一 commit 打出两个版本号」的隐患 |
| 凭据存储 | AK/SK 仅存服务端会话，Fernet 加密落库 | 不向浏览器下发凭据，与双角色 + 会话可吊销安全模型一致 |
| 下载原子性 | 临时文件 + `os.replace` | 失败 / 取消不留半截文件、不覆盖本地旧文件 |
| 文件夹语义 | 文件夹走整棵子树操作，不假装支持重命名 | S3 无目录概念，文件夹只是 `/` 结尾零字节占位对象 |
| 搜索上限 | 扫描 / LIST / 返回三上限 + 截断提示 | 大桶浏览的成本边界，避免无界扫描 |
| 依赖上界 | 全部声明版本上界，与实际扫描结果一起维护 | 打包冻结依赖；但上界可能挡安全补丁，必须配合 `pip-audit` 核验 |
| src 布局 | 包目录 `objstoreexplorer` 置于 `src/`，包名=发行名 | 标准可安装布局，`pip install -e .` 后 `python -m objstoreexplorer` 与控制台入口自洽 |
