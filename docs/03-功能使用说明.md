# ObjStoreExplorer — 功能使用说明

> 本文严格依据 当前源码编写，覆盖**桌面版**与 **Web 容器版**两种形态的功能使用。
> 桌面版与 Web 版功能高度重合，差异处单独标注。所有页面标题、操作入口均为源码原文。
> 部署方式见 [02-环境部署教程](./02-环境部署教程.md)。

---

## 1. 第一次使用

```
启动 → 顶部「连接」→ 填服务器信息 → 连接 → 从左侧导航进入各功能
```

- **桌面版**：`python -m objstoreexplorer` 启动后，顶部工具栏点「连接」。
- **Web 版**：浏览器打开 `http://服务器IP:6083`，用 admin 账号登录后，顶部「连接」配置 S3。

### 1.1 连接服务器

填写：

| 字段 | 怎么填 | 例子 |
|---|---|---|
| 名称 | 自己起个好认的名字 | `minio-prod` |
| Endpoint | `主机:端口` 或带协议 | `192.168.1.247:9000` |
| Access Key | S3 用户的 AK | `minioadmin` |
| Secret Key | S3 用户的 SK | `minioadmin` |
| SSL | 内网 HTTP **不勾**；公网 HTTPS 勾上 | |
| 外链 Host（Web 版可选） | 预签名按外部主机名重新签名（容器内网部署用） | `files.example.com` |

**填法要点**：

- 端口**要写**。不写端口也不写协议时按 MinIO 默认补 **9000**（不是 80）。服务在 80 端口必须显式写 `:80`
- Endpoint 里**不要**带路径，程序只取 `主机:端口`
- 连过的服务器存进历史，下次从 Endpoint 框下拉里选，不用重填
- Web 版连接对话框有「测试连接」按钮——只验证 Endpoint/AK/SK 可达可用，不保存历史，
  成功后立即断开，不占用会话连接位

> AK/SK 用 Fernet 加密后落库，**不明文落盘**，SK 永不回传前端。

### 1.2 全局快捷键（桌面版）

| 快捷键 | 作用 |
|---|---|
| `F5` / `Ctrl+R` | 刷新当前页 |
| `Ctrl+O` | 上传文件 |
| `Ctrl+D` | 下载选中对象 |
| `Ctrl+N` | 新建（按当前页语义） |
| `Delete` | 删除选中 |
| `F2` | 重命名选中 |
| `Esc` | 关闭当前对话框 |

> Web 版对象页支持 `Delete` 删除、`F2` 重命名、`Ctrl+A` 全选（仅 admin 写权限生效，
> 焦点在输入框 / 下拉时不拦截）。

## 2. 存储总览

> 并发统计全部存储桶的对象数、文件夹数与容量占用（含占比条可视化）；桶多时首次加载需要数十秒。

点「刷新」重新统计。统计对**每个桶**发一次列举请求，桶多或单桶对象多时较慢是正常的。
异常桶以红色标示。Web 版按 viewer/admin 均可查看。

## 3. 存储桶空间

> 创建、删除与统计 S3 存储桶；进入桶可管理对象。

| 操作 | 怎么做 | 注意 |
|---|---|---|
| 建桶 | 「创建桶」按钮 | 桶名需符合 S3 命名规则（小写字母 / 数字 / 点 / 连字符） |
| 进桶 | 双击某一行 | 跳到对象页 |
| 删桶 | 选中（可多选）→「删除选中」 | **桶内所有数据将被永久删除**，二次确认；版本化桶先清全部历史版本 |
| 桶策略 | 选中桶→「桶策略」 | 见 §3.1 |
| CORS / 分片清理（Web 版） | 桶管理页「跨域配置」「分片清理」卡片 | admin only，见 §3.2 |

### 3.1 桶访问策略

控制「谁能访问这个桶」——匿名可下载、限制来源、限定请求方式等。三个预设：

| 预设 | 效果 | 风险 |
|---|---|---|
| 私有（推荐） | 显式 Deny 全部匿名访问 | 无 |
| 公共读（匿名可下载） | 任何人凭链接可下载 | **高**——套用时额外弹确认 |
| 公共读写（极危险） | 任何人可上传 / 删除 | **极高**——同上 |

也可直接编辑 JSON。编辑器提供：**格式化**（语法检查并指出行号）、**查看当前**（看服务端现存策略）、
**下发策略**（提交前展示新旧对比，`Principal` 含 `*` 时红字警告）、**删除策略**（恢复私有）。

> ⚠ 一个 `Principal: {"AWS": ["*"]}` 的 `GetObject` 策略 = 把整个桶公开在互联网上。
> **删掉策略后，已经流出去的链接仍然有效**——匿名下载无法通过本程序收回。

### 3.2 CORS 与分片清理（Web 版）

- **跨域配置**：查看 / 保存 / 删除桶级 CORS 规则（admin only，JSON 校验）。
- **分片清理**：列举 / 中止桶内未完成的分段上传，中断上传不再 invisible 计费。

## 4. 对象资源管理

> 上传、下载、重命名、复制 / 剪切 / 粘贴与批量删除；双击进入目录，右键查看更多操作。

### 4.1 导航

- 顶部面包屑显示当前位置，任意一段可点击跳转
- 双击文件夹行进入；每层顶部有 `..` 行返回上级

### 4.2 上传

`Ctrl+O` 或工具栏「上传」→ 选文件，**支持多选**。Web 版额外支持三种入口：

- 按钮选文件
- **目录选择器**（`webkitdirectory`，保留根目录层级）——文件夹结构上传
- **表格区整片拖拽**（`webkitGetAsEntry` 递归遍历）

上传在后台执行，界面不卡；进度显示在顶部状态栏。单文件上限默认 100 MB（系统设置可改）。
上传中可取消；**分片传输下取消会在分片边界中断**（不留半截对象）。
Web 版超限文件在**落盘前**即被拒绝（400 + 中文提示）。

任务面板（顶部任务按钮）支持对进行中的上传 / 打包下载任务**暂停 / 恢复 / 取消**：
暂停在文件边界生效（分片上传在分片边界等待，已建连接不拆），已暂停任务以「已暂停」标记展示。

> 已知限制：暂停状态保存在执行节点的内存中——多 worker 部署下从另一节点发起的暂停请求会
> 如实提示「不支持」；**取消**不受此限制（已落库跨节点生效）。

### 4.3 下载

选中对象 → `Ctrl+D` 或右键「下载」。

- 大文件（>5MB）或非文本类型**不会自动打开**，先问「下载还是预览」
- 预览走本地缓存，同一对象重复预览不重复下载；缓存上限 100 MB，超出自动清理
- Web 版下载支持**打包下载**（文件夹展开成子 key 打包成 zip）与**预签名分享**（见 §4.9）
- 下载采用**暂存 + 校验 + 原子替换**（`.part` 暂存文件）：失败 / 中断不留半截文件，
  旧文件不被覆盖；服务端校验文件大小，不通过会明确报错并保留原文件

> 下载文件名已做清洗：带 `: * ? < > |` 的对象、保留名（`CON` / `NUL` / `COM1`）、
> 路径穿越（`../`）均安全落盘；同名不同目录自动加 `(2)` `(3)` 后缀，不互相覆盖。

### 4.4 在线预览（v0.1.0）

- **图片**（7 类扩展名）直显；**文本**（30+ 类）按扩展名白名单判型，定长读取不落盘
- 文本类一律降级 `text/plain` 输出（桶里存 `.html` / `.js` 也只做纯文本展示，堵死存储型 XSS）
- 全响应带 `X-Content-Type-Options: nosniff`；svg 明确排除（可内嵌脚本）；图片超 2MB 拒绝
- 文本预览**编码自动识别**：BOM → UTF-8 → GB18030 → Big5 → Shift-JIS → Latin-1 兜底，
  响应带 `X-Preview-Encoding` 头标注实际编码

### 4.5 复制 / 剪切 / 粘贴

| 操作 | 含义 |
|---|---|
| 复制 | 保留源对象 |
| 剪切 | 粘贴后删除源对象 |
| 粘贴 | 粘到当前目录（跨桶时明确提示目标桶） |

文件夹的复制 / 剪切按整棵子树操作；任一项失败保留剪贴板以便重试。

### 4.6 过滤搜索

对象页工具栏搜索框，对**当前已加载列表**做本地按名称模糊匹配（不区分大小写，清空即恢复）。
这是**当前目录内**过滤，非全桶递归检索（全桶递归检索在桌面版「同步管理」页 / Web 版对象页搜索接口，
带三上限：扫描 50000 对象 / 返回 1000 条，截断时明示「结果可能不完整」）。
关键词与对象名匹配前做 Unicode NFC 归一化，修复 macOS NFD 上传「明明有却搜不到」。

### 4.7 重命名

选中 → `F2` → 输入新名。**只能同层重命名**，程序严格比对对象名末段，对不上直接报错。

> ⚠ **不支持文件夹重命名。** S3 无目录概念，文件夹只是「以 `/` 结尾的零字节对象」。
> Web 版文件夹的**移动**走逐源语义：每条 copy 成功后立即删该条旧 key，部分失败如实报告新旧各一份。

### 4.8 删除

选中（可多选）→ `Delete` → 确认。批量删除显示成功 / 失败明细，失败项提供「重试失败项」。
Web 版删除任务支持**取消**（分批 + 批间取消检查点，取消后未处理条目如实记「已取消」）；
文件夹走整棵子树删除。

### 4.9 对象属性与分享

**属性**（右键「属性」）：名称、大小、类型、ETag、修改时间、**自定义元数据**（`x-amz-meta-*`）、
**标签**（S3 Tagging）。长内容在可滚动查看窗里，双击选词 / `Ctrl+A` 全选 / `Ctrl+C` 复制。

**公开性检查**（Web 版）：对象详情附带匿名 HEAD 探测，展示「公开 / 私有」标记，误公开变可见信号。

**预签名分享**（Web 版）：文件行操作列「分享」→ 选有效期（1 小时 / 24 小时 / 7 天）→
生成带签名下载直链 → 一键复制。签发后无法单独吊销，泄露请轮换 Access Key。

## 5. 同步管理（桌面版独有）

> 本地 ↔ 远端双向同步：推送 / 拉取 / 镜像三种方向，冲突逐个确认。

### 5.1 三种方向

| 方向 | 含义 |
|---|---|
| 推送 | 本地 → 远端（以上传 / 覆盖为主） |
| 拉取 | 远端 → 本地（以下载 / 覆盖为主） |
| 镜像 | 双向 + 删除目标端多余 |

> ⚠ **镜像模式会删除目标端多余的文件。** 勾选后明确列出将要删除的项并二次确认。
> 切回推送 / 拉取方向时该勾选**自动失效**。

### 5.2 冲突处理

同 key 但内容不同的文件，逐个弹窗选择：用本地覆盖 / 用远端覆盖 / 跳过。
可勾选「对所有剩余冲突应用相同选择」。选「取消整次同步」后，已排入队列的操作不再执行。

同步执行期间，进度窗口支持**暂停 / 恢复 / 取消**：暂停在文件与分片边界生效（已建连接不拆，
大文件分片上传停在当前分片边界），恢复后继续；取消与暂停可随时切换，取消优先。

### 5.3 同步历史

页面下方记录最近同步活动，切换回该页自动刷新。

> Web 版不提供同步功能——本地磁盘目录在访问者机器上，服务端无法触达，同步能力天然属于桌面版。

## 6. MinIO 用户

> 创建 S3 账号、切换启用状态、重置 Secret Key（需要 Admin API 权限）。

| 操作 | 说明 |
|---|---|
| 创建用户 | 填 AK/SK，可同时创建并附加策略 |
| 一键创建 | 桶 + 用户 + 策略一次做完，**任一步失败自动回滚** |
| 启停用 | 停用后该用户无法登录 |
| 重置密码 | 删除重建，**自动还原策略与组身份** |

> ⚠ 用户 / 策略管理走 MinIO Admin API，**AK/SK 必须有 admin 权限**，否则提示权限不足。
> 「一键创建」若目标 AK 已存在，明确显示「用户已存在，密码不可查询」，**不会**编造一个密码。

## 7. 访问策略

> 以 JSON 语句描述 S3 权限边界；选择策略查看内容，再附加到指定用户。

| 操作 | 说明 |
|---|---|
| 查看 | 左侧选中，右侧显示 JSON |
| 创建 | 填名称 + JSON |
| 编辑 | 修改内容（自动保留所有用户的其他策略与组身份） |
| 删除 | 删除策略 |
| **附加到用户** | 选中策略 →「附加」→ 选用户 |
| **分离** | 同上，点已附加的用户移除 |

> 修改策略内容时，程序先快照每个受影响用户的完整策略列表与组身份，改完整体写回。
> 此前 MinIO 的 `detach_policy` 会把用户其他策略一起抹掉，且无回滚。

## 8. 版本控制

> 为存储桶开启对象版本化；暂停后新写入不再产生版本，但历史版本仍保留。

选桶 → 选 `Enabled` / `Suspended` → 应用。

- 桶一旦启用版本化就**无法彻底关闭**（S3 协议限制），只能暂停
- 暂停状态下删除对象会写入删除标记，历史版本仍在
- **Web 版支持对象历史版本浏览 / 恢复 / 删除**：误覆盖 / 误删后可在 Web 自助恢复任意历史版本；
  删除标记与当前版本均有前置拦截，写操作记审计日志

## 9. 生命周期规则

> 按前缀设置对象自动过期天数，MinIO 后台扫描器定期清理到期对象回收空间。

选桶 → 填 JSON →「应用规则」。支持的规则动作：

| 动作 | JSON 字段 |
|---|---|
| 当前版本过期 | `Expiration: {"Days": N}` |
| 非当前版本过期 | `NoncurrentVersionExpiration: {"NoncurrentDays": N}` |
| 存储层级转换 | `Transitions: [{"Days": N, "StorageClass": "STANDARD_IA"}]` |
| 中止未完成分片 | `AbortIncompleteMultipartUpload: {"DaysAfterInitiation": N}` |

> ⚠ 应用规则会**整体覆盖**桶里已有的全部规则。已有规则时弹确认并展示新旧对比。

## 13. Web 版角色与权限

Web 版为**多人浏览器访问**，分两角色：

| 角色 | 权限 |
|---|---|
| **viewer（只读）** | 浏览 / 搜索 / 下载 / 分享 / 查看日志与设置（只读） |
| **admin（全权）** | viewer 全部 + 建删桶 / 上传删除重命名 / 用户与策略管理 / 版本与生命周期 / 设置修改 |

权限**逐路由服务端校验**（非仅前端隐藏）。登录有双层防爆破（IP 限速 + 账号锁定）、
防用户名枚举、会话过期强制改密。详见 [04-安全设计说明](./04-安全设计说明.md)。

## 14. 已知限制

- 对象列表为客户端分批（未接服务端 `max_keys/marker`），十万级以上对象桶首次加载偏慢
- 对象搜索是当前目录过滤，非全桶递归检索（全桶检索带三上限）
- 不支持文件夹重命名（S3 无目录概念，程序不假装支持）
- 桌面版同步、截图、密钥 ACL 等本机能力不在 Web 版范围
- 预签名链接签发后无法单独吊销，到期前任何持有者均可下载
